# 用户配置字段说明

这份文档用于解释 `user_config_info.json` 中各字段的含义。生成落地页时，`user_config_info.json` 是唯一配置来源。

## 读取原则

- 先读取并解析 `user_config_info.json`，再生成页面。
- 配置文件中的开关、字段和科目优先级高于默认页面想法。
- 信息缺失时，可以在页面中使用可编辑占位内容，但不能编造真实数据、评价、资质或合作背书。

## 根字段

| 配置模块 | 字段名 | 含义 | 说明 |
| --- | --- | --- | --- |
| 基础配置 | `version` | 配置文件版本号 | 用于兼容校验。 |
| 基础配置 | `project` | 项目核心配置 | 落地页核心项目信息分组。 |
| 交付配置 | `delivery` | 交付功能配置 | 落地页交付与转化功能配置。 |
| 表单字段配置 | `fields` | 表单字段列表 | 预约或留资表单字段配置。 |

## `project`

| 字段名 | 含义 | 说明 |
| --- | --- | --- |
| `name` | 落地页名称 | 用于页面标题、项目标识和运营识别。 |
| `subject` | 科目 | 仅支持 `中文`、`数学`、`英文`。 |
| `language` | 页面语言 | 常见值为 `简体中文` 或英文。 |
| `theme` | 落地页主题 | 影响首屏角度、文案方向和视觉表达。 |
| `notes` | 落地页需求详情 | 用于指导页面生成，但不能覆盖业务硬规则。 |

## `delivery`

| 字段名 | 含义 | 说明 |
| --- | --- | --- |
| `devices` | 支持设备 | 至少包含 `PC` 或 `移动端` 之一；两者都有时优先移动端体验。 |
| `booking` | 约课开关 | `true` 表示启用试听课预约链路；`false` 表示仅留资。 |
| `multiChild` | 多娃开关 | `true` 表示支持继续为其他孩子报名或约课。 |
| `multiSubject` | 多科开关 | `true` 表示支持配置内科目的拓科选择，禁止新增未配置科目。 |
| `maxChildren` | 最多可约孩子数量 | 范围为 1-3；开启多娃时必须遵守。 |
| `phoneVerify` | 手机号验证功能 | `true` 表示手机号字段需要验证码或验证交互。 |
| `emailVerify` | 邮箱验证功能 | `true` 表示邮箱字段需要验证码或验证交互。 |

缺失的可选布尔值默认按 `false` 处理，除非用户另有明确说明。

## `fields`

每个字段对象包含：

| 字段名 | 含义 |
| --- | --- |
| `id` | 稳定字段标识。 |
| `label` | 页面展示给用户看的字段名称。 |
| `enabled` | 是否在表单中展示并收集该字段。 |
| `locked` | 是否为配置锁定字段，不应被删除。 |

已知字段 ID：

| ID | 含义 | 规则 |
| --- | --- | --- |
| `name` | 孩子称呼 | 用于识别孩子。 |
| `phone` | 家长手机号 | 手机和邮箱至少启用一个。 |
| `email` | 家长邮箱 | 手机和邮箱至少启用一个。 |
| `age` | 孩子年龄 | 中文课程必须启用。 |
| `level` | 中文水平 | 中文课程必须启用。 |
| `grade` | 孩子年级 | 英文和数学课程必须启用。 |
| `region` | 所在地区 | 必须启用，不可删除。 |
| `language` | 沟通语言 | 用于后续顾问沟通。 |

所有 `enabled: true` 的字段都视为用户必填字段。隐私同意模块必须在页面中展示，即使它不是普通 `fields` 字段。

## 选择型字段默认选项

当 `user_config_info.json` 没有为选择型字段提供 `options` 时，生成页面交互时使用本节默认选项。若 JSON 中显式提供 `options`，以 JSON 配置为准。

### 科目选项

`project.subject` 支持以下选项：

| 值 | 页面展示 |
| --- | --- |
| `中文` | 中文 |
| `数学` | 数学 |
| `英文` | 英文 |

### 年龄字段选项

`fields.age` 应生成为选择控件，不要默认做成纯文本输入。根据 `project.subject` 使用对应年龄选项和服务范围提示。

| 科目 | 年龄选项 | 服务范围 | 生成要求 |
| --- | --- | --- | --- |
| `中文` | `1岁` 至 `18岁`，`18岁+` | 3-18岁 | 表单选项保留完整年龄选项；服务范围可作为提示文案或后续顾问判断依据。 |
| `数学` | `1岁` 至 `15岁`，`15岁+` | 6-15岁 | 表单选项保留完整年龄选项；服务范围可作为提示文案或后续顾问判断依据。 |
| `英文` | `1岁` 至 `12岁`，`12岁+` | 5-12岁 | 表单选项保留完整年龄选项；服务范围可作为提示文案或后续顾问判断依据。 |

实现时可按以下方式展开选项：

- 中文：`1岁`, `2岁`, `3岁`, `4岁`, `5岁`, `6岁`, `7岁`, `8岁`, `9岁`, `10岁`, `11岁`, `12岁`, `13岁`, `14岁`, `15岁`, `16岁`, `17岁`, `18岁`, `18岁+`
- 数学：`1岁`, `2岁`, `3岁`, `4岁`, `5岁`, `6岁`, `7岁`, `8岁`, `9岁`, `10岁`, `11岁`, `12岁`, `13岁`, `14岁`, `15岁`, `15岁+`
- 英文：`1岁`, `2岁`, `3岁`, `4岁`, `5岁`, `6岁`, `7岁`, `8岁`, `9岁`, `10岁`, `11岁`, `12岁`, `12岁+`

### 中文水平字段选项

当 `project.subject` 为 `中文` 且启用 `fields.level` 时，`fields.level` 应生成为单选列表、下拉选择或分步选择题。默认选项如下：

| 值 | 页面展示 |
| --- | --- |
| `no_experience` | 无中文学习经验 |
| `daily_conversation` | 没学过，但能进行日常交流 |
| `under_1_year` | <1年学习经验 |
| `1_to_2_years` | 1-2年学习经验 |
| `over_2_years` | 2+年学习经验 |
| `native_speaker` | 母语是中文 |

生成交互时应展示中文文案，提交数据时可使用稳定值。若页面不区分值和文案，也可以直接提交中文展示文案。

### 沟通语言字段选项

当启用 `fields.language` 且 JSON 未提供选项时，默认使用：

| 值 | 页面展示 |
| --- | --- |
| `zh` | 中文 |
| `en` | 英文 |

### 设备选项

`delivery.devices` 支持：

| 值 | 含义 |
| --- | --- |
| `PC` | 电脑端 |
| `移动端` | 移动端 |

当同时包含 `PC` 和 `移动端` 时，页面必须同时适配两端，并优先保证移动端填写体验。
